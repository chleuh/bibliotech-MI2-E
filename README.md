# CY Bibliothèque - Projet en C

Ce projet est un programme de gestion d'une bibliothèque municipale écrit en langage C, permettant la gestion des utilisateurs, des livres et des emprunts avec suivi des retards.

# Compilation

Assurez-vous d’avoir le compilateur 'gcc' et l’outil `make' installés.

Ouvrez un terminal.

Placez-vous dans le dossier du projet.

Tapez la commande suivante pour compiler :

make

Cela générera un exécutable nommé 'exec'.

# Exécution
Pour lancer le programme, tapez simplement :

./exec

# Nettoyage 
Pour supprimer les fichiers objets et l’exécutable générés :

make clean
